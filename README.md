## 🌟 نبذة عن المشروع
منصة ويب تفاعلية متكاملة موجهة لطلبة كلية الحاسبات والمعلومات وهندسة البرمجيات، مصممة لمساعدة الطلاب والفرق على بدء مسيرتهم التقنية من الصفر وإنجاز مشاريع تخرج احترافية بأعلى معايير الجودة التقنية والمعمارية.

---

## 🚀 طريقة تشغيل المشروع محلياً على جهازك

### 1. المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (إصدار 18 أو أحدث).
- محرر الأكواد [VS Code](https://code.visualstudio.com/).

### 2. خطوات التثبيت والتشغيل
```bash
# 1. تثبيت الحزم والمكتبات
npm install

# 2. تشغيل السيرفر وخادم التطوير (Full-stack Express + Vite)
npm run dev
```

افتح المتصفح على الرابط:
`http://localhost:3000`

## 📱 كيفية تثبيت الموقع كتطبيق على جهازك (PWA / Offline App)

### 💻 على الكمبيوتر (Windows / Mac / Linux):
1. افتح الموقع في متصفح **Google Chrome** أو **Microsoft Edge**.
2. ستجد أيقونة تثبيت (شعار شاشة مع سهم أو علامة ⊕) في أقصى يمين شريط العنوان (URL bar).
3. اضغط على **تثبيت (Install)**.
4. سيصبح لديك تطبيق مستقل في قائمة ابدأ وسطح المكتب يعمل دون الحاجة لفتح المتصفح وبدون إنترنت!

### 📱 على الهاتف (Android / iPhone):
- **Android (Chrome)**: اضغط على القائمة (الثلاث نقاط ⋮) في أعلى المتصفح، ثم اختر **"إضافة إلى الشاشة الرئيسية" (Add to Home screen)** أو **"تثبيت التطبيق" (Install app)**.
- **iPhone / iOS (Safari)**: اضغط على زر المشاركة (Share ⎋) في الأسفل، ثم مرر واختر **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)**.

## 📦 محتويات وميزات المنصة
1. **مسارات تعليمية من الصفر**:
   - تحليل النظم وهندسة المعمارية (ERD, DFD, Activity Diagrams).
   - قواعد البيانات العلائقية والوثائقية (SQL & NoSQL).
   - تطوير الواجهات الخلفية (Node.js & Express & APIs).
   - تطوير الواجهات الأمامية (HTML, CSS, Modern JavaScript & React).
   - بايثون لتطبيقات الذكاء الاصطناعي ومعالجة البيانات.
   - هندسة التوجيه والـ Vibe Coding.
2. **فضاء مخصص لكل فريق تخرج مع كلمة مرور سرية**:
   - إمكانية إنشاء أو تسجيل دخول لكل تيم بكلمة مرور خاصة.
   - توزيع ومتابعة مهام الأعضاء (Kanban Board) وتعيين الأولوية.
   - تتبع معايير الجودة ومراحل التسليم الأكاديمي.
   - تصدير تقرير التقييم الفردي والجماعي بصيغة PDF.
3. **مركز اختبارات وتقييم دوري**:
   - اختبارات شاملة لكل مسار مع تحليل فوري وتغذية راجعة ثنائية اللغة.
4. **معمل الذكاء الاصطناعي وبرومتات البرمجة (AI & Vibe Coding Lab)**:
   - بنك برومتات متخصصة لتوليد هياكل النظم والـ ERD وكتابة وتصحيح الأكواد.
5. **دليل احتراف Git & GitHub**:
   - أوامر Git التفاعلية، خطة Git Flow لفريق التخرج، ونموذج README جاهز.
6. **التقويم وجدول المذاكرة والملاحظات الصوتية**:
   - تسجيل الملاحظات الصوتية مع النصوص، والتنبيهات اليومية.
7. **إمكانية الوصول وتعدد اللغات**:
   - دعم كامل للغتين العربية والإنجليزية مع تغيير اتجاه الصفحة (RTL/LTR).
   - الوضع الليلي (Dark Mode) ووضع التباين العالي وقارئ الشاشة الصوتي.
